A **Reference design** (ux-studio `CONTEXT.md`) is one `DESIGN.md` from VoltAgent's awesome-design-md, pinned to the commit in `INDEX.md`. It is evidence and a starting base for the **Project DESIGN.md**, never shipped as-is.

## Steps

1. **Pick.** Read [INDEX.md](INDEX.md). Choose one reference (two at most) whose character matches the brief: the site the user named, else the closest category and character. Say which and why in one line.
2. **Fetch.** Download it from the pinned URL pattern at the top of `INDEX.md`, substituting the slug, with WebFetch or `curl -fsSL`. Fetch only what you picked.
3. **Use.** Treat its tokens (colours, type, radii, spacing) and rules as a base. Adapt them to the project's brand and content, then write or extend the project's own `DESIGN.md`. Keep the reference out of the project tree.

Done when the Project DESIGN.md exists and names which reference informed it.

`INDEX.md` and `upstream-README.md` are generated by `scripts/sync-vendor.sh`; refresh them through that script, not by hand.
